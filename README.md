Primus Sangama Website

Overview
Primus Sangama is a modern, multigenerational living community website showcasing lifestyle, amenities, and plans in Bengaluru. Built with PHP, HTML, CSS, and JavaScript, it provides an interactive, responsive, and visually appealing user experience.

Features
-> Responsive banner & about sections
-> Interactive “Sangama of Three” charts & sliders
-> Amenities & plans sliders
-> Google Maps integration & location highlights
-> Contact form with preferred communication options
-> FAQ accordion section

Technologies

Frontend: HTML, CSS, JavaScript, Bootstrap 5
Backend: PHP (header & footer templates)
Libraries: Owl Carousel, Google Maps Embed API

Setup
Clone the repo:
git clone https://github.com/vasanth154/primus-lead-page-clone.git

Place in your PHP server (htdocs for XAMPP/WAMP)
Open in browser:http://localhost/primus/Primus-lead-page-clone/index.php
